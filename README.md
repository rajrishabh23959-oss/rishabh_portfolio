## ✨ Overview

Welcome to **Rishabh’s Scrapbook Studio** — an artisanal, high-performance static web portfolio engineered with pure **HTML5, CSS3, and modern Vanilla JavaScript**. 

Designed with an eclectic **Scrapbook Aesthetic** (torn-paper edges, washi tape pins, 3D tilt polaroids, custom dot-grid textures, interactive physics canvas, and Konami code easter eggs), this repository hosts Rishabh's complete digital presence along with two fully playable and research-grade standalone sub-applications:
1. **[`sentinai.html`](sentinai.html)**: An interactive **AI Behavioral Biometrics Keystroke Dynamics Simulator** with real-time neural authentication telemetry.
2. **[`game.html`](game.html)**: **Treasure Hunter**, an arcade-grade 10-level 2D retro dungeon crawler engine with custom Swept AABB collision mechanics.

## 🎮 Interactive Standalone Modules

This repository isn't just a portfolio — it's an ecosystem of interactive web tools built directly with zero third-party framework overhead:

### 1. 🛡️ SentinAI (`sentinai.html`) — Keystroke Dynamics Simulator
- **Live Cyberpunk Telemetry**: Real-time neural biometrics dashboard.
- **Flight & Hold Time Heatmap**: Captures microsecond typing latency, keystroke overlap, and user dwell rhythms.
- **Continuous Anti-Fraud Verification**: Visualizes how a bank can authenticate identity continuously in the background without SMS OTP friction.

### 2. 🕹️ Treasure Hunter (`game.html`) — 10-Level Retro Game Engine
- **Pure Canvas Physics**: 60 FPS particle loop rendered using vanilla JavaScript.
- **Swept AABB Collision**: Eliminates wall-clipping and entity-tunneling bugs.
- **Arcade Features**: Dynamic health bars, dungeon keys, enemy patrol AI, hazard traps, and retro 8-bit sound effects.

## 🚀 Quick Start & Local Run

Because this project is built entirely on standard Web APIs without heavy bundler dependencies, you can run it instantly anywhere.

### Option 1: Direct Browser Launch
Simply double-click or open [`index.html`](index.html) in any modern browser (*Chrome, Edge, Firefox, Safari*).

### Option 2: Run with Python HTTP Server
```bash
# 1. Clone the repository
git clone https://github.com/rajrishabh23959-oss/rishabh_portfolio.git

# 2. Navigate into the directory
cd rishabh_portfolio

# 3. Launch lightweight HTTP server
python -m http.server 3000

# 4. Open in your browser:
# http://localhost:3000
```

### Option 3: Run with Node.js / npx serve
```bash
npx serve .
```

### Option 4: VS Code Live Server
1. Open the project folder in **VS Code**.
2. Right-click [`index.html`](index.html) and select **"Open with Live Server"**.
