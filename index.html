🔍 Fix This Bug: Treasure Hunter Interactive

The Problem: At low speeds, the player collides with walls perfectly. But at high speeds, the player "tunnels" right through solid walls.

# Original PyGame Collision Logic def check_collision(player_rect, wall_rect):
if player_rect.colliderect(wall_rect): return True # FAILS AT HIGH SPEED!
return False
The Fix: Swept AABB Collision

Instead of just checking if two rectangles overlap at the current frame, we must check the path the player travelled since the last frame. If the distance moved in one frame is larger than the wall's thickness, `colliderect` never catches the overlap.

I rewrote the physics engine to use velocity vectors and raycasting along the movement path. This catches the collision before the player tunnels through.
